# Лабораторная 1, задача 1

> Написать программу, где каждый поток печатает свой идентификатор, количество потоков всего и строчку `Hello World`. Запустить программу с 8 потоками. Всегда ли вывод идентичен? Почему?

## Запуск

```bash
cd lab1/task1
dotnet run -c Release -- 8
```

Формат: `<число_потоков> [размер_задачи]`. Второй аргумент принимается для единообразия и на логику не влияет.

## Ответ на вопрос

Нет, вывод не всегда идентичен. Потоки стартуют почти одновременно, а порядок их выполнения определяет планировщик операционной системы, поэтому порядок строк от запуска к запуску меняется. Каждая строка при этом выводится целиком, так как `Console.WriteLine` синхронизирован.

## Реализация

В цикле создаются `N` объектов `Thread`, каждый печатает свой `id` и `N`. Главный поток дожидается всех через `Join()`.

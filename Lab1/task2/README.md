# Лабораторная 1, задача 2

> Массив из 16000 элементов, `a[i] = i`. Результирующий массив: для всех элементов, кроме крайних, `b[i] = (a[i-1] + a[i] + a[i+1]) / 3.0`. Запустить с 8 потоками при различных типах распределения работ.

Крайние элементы `b[0]` и `b[n-1]` не вычисляются и остаются нулевыми. Так как `a[i] = i`, то `b[i] = i`, что используется для проверки.

## Запуск

```bash
cd lab1/task2
dotnet run -c Release -- 8 16000 static
dotnet run -c Release -- 8 16000 static 1000
dotnet run -c Release -- 8 16000 dynamic 100
dotnet run -c Release -- 8 16000 guided 100
```

Режим `runtime` берёт тип из переменной окружения `LAB2_SCHEDULE` или `OMP_SCHEDULE` (формат `тип[,chunk]`):

```bash
# Linux/macOS
OMP_SCHEDULE=guided,200 dotnet run -c Release -- 8 16000 runtime
# Windows PowerShell
$env:OMP_SCHEDULE="guided,200"; dotnet run -c Release -- 8 16000 runtime
```

Формат: `<число_потоков> <размер_массива> [static|dynamic|guided|runtime] [chunk]`. По умолчанию `static`.

## Типы распределения

| Тип       | Реализация                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| `static`  | без chunk: по одному непрерывному блоку на поток; с chunk: блоки размера chunk раздаются потокам по кругу   |
| `dynamic` | свободный поток берёт следующий блок размера chunk (по умолчанию 1); счётчик защищён `lock`                  |
| `guided`  | размер блока = оставшееся число итераций / число потоков, но не меньше chunk; выдача под `lock`              |
| `runtime` | тип и chunk читаются из переменной окружения                                                                 |

Программа выводит для каждого потока число выполненных итераций и блоков, время, контрольную сумму и `OK: true`, если результат совпал с последовательным.

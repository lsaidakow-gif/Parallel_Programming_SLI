# Лабораторная 1, задача 3

> Модифицируйте задачу 1 так, чтобы потоки распечатывали свои идентификаторы в обратном порядке. Существует как минимум 5 способов решения.

## Способы

1. `mutex`: активное ожидание, поток крутится на атомарном счётчике очереди (`Volatile`, `Interlocked`, `SpinWait`).
2. `cond`: пассивное ожидание через `Monitor.Wait` / `Monitor.PulseAll`.
3. `chan_chain`: цепочка очередей `BlockingCollection`, эстафета от старшего потока к младшему.
4. `chan_array`: координатор по очереди даёт слово потокам через массив очередей и ждёт подтверждения.
5. `wg_chain`: цепочка на `CountdownEvent` (аналог WaitGroup): поток `id` ждёт завершения потока `id+1`.

## Запуск

```bash
cd lab1/task3
dotnet run -c Release -- 8 1000                # все способы
dotnet run -c Release -- 8 1000 cond           # один способ
```

Формат: `<число_потоков> <число_повторов> [mutex|cond|chan_chain|chan_array|wg_chain]`.

Для каждого способа первый запуск печатает вывод потоков, а затем способ повторяется ещё `число_повторов - 1` раз без вывода, и проверяется, что порядок каждый раз строго обратный. Итог: `OK: true`.

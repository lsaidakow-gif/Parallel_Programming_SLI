# Лабораторная 2, задача 4

> Напишите программу перемножения больших матриц. Сравните время выполнения последовательной и параллельной программы на 2, 4, 8 потоках.

## Что реализовано

- последовательное умножение матриц;
- параллельное умножение: строки результата делятся на непрерывные блоки между потоками;
- проверка корректности по контрольной сумме (последовательная и параллельная версии);
- замер времени (`Stopwatch`), расчёт ускорения `speedup = T_посл / T_паралл` и эффективности `speedup / число_потоков`;
- прогрев JIT перед замером.

Матрицы хранятся в одномерных массивах `double[]`, порядок циклов `i -> k -> j` уменьшает число промахов кэша по сравнению с `i -> j -> k`.

## Запуск

```bash
cd lab2
dotnet run -c Release -- 1 1000
dotnet run -c Release -- 2 1000
dotnet run -c Release -- 4 1000
dotnet run -c Release -- 8 1000
```

Формат: `<число_потоков> <размер_матрицы>`, размер до 10000. Значение `Results Match: true` означает, что результаты совпали.

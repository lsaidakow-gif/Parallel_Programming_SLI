# Лабораторная 3, задача 5

> Напишите программу, которая читает из файла координаты точек в 3D пространстве (x, y, z) и вычисляет геометрический центр, который есть среднее по x, y и z. Напишите две версии программы: одну с распараллеливанием цикла, другую с функциональной декомпозицией.

## Формат входного файла

По одной точке в строке: три числа через пробел, десятичный разделитель - точка. Пустые строки и строки, начинающиеся с `#`, пропускаются. Пример - файл `sample_points.txt` (вершины единичного куба, центр `(0.5, 0.5, 0.5)`).

Большой файл со случайными точками из диапазона [-100; 100] создаётся самой программой:

```bash
cd lab3
dotnet run -c Release -- gen points.txt 10000000
```

## Запуск

```bash
cd lab3
dotnet run -c Release -- 8 sample_points.txt            # обе версии
dotnet run -c Release -- 8 points.txt loop              # только распараллеливание цикла
dotnet run -c Release -- 8 points.txt functional        # только функциональная декомпозиция
```

Формат: `<число_потоков> <файл> [loop|functional|all]`. Для замеров времени используйте конфигурацию Release и большой файл.

## Версии

| Версия       | Идея                                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `loop`       | Декомпозиция по данным: точки делятся на непрерывные блоки, каждый поток считает частичные суммы x, y, z, затем суммы объединяются (аналог `reduction`). |
| `functional` | Декомпозиция по функциям: три потока независимо считают среднее по x, среднее по y и среднее по z. Число потоков всегда 3.  |

Результат каждой версии сравнивается с последовательным (с относительной погрешностью 1e-9, так как порядок сложения чисел с плавающей точкой различается). Итог: `OK: true`.

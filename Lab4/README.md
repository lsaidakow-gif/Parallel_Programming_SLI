# Лабораторная 4, задача 6

> Используя функциональную декомпозицию, перепишите задачу 5 для вычисления значения по формуле `(Σx + Σy + Σz) / 3N`, где N - количество точек. Используйте глобальную сумму и критические секции.

## Что реализовано

Функциональная декомпозиция: три потока, по одному на координату. Каждый поток считает сумму своей координаты и добавляет её в **общую (глобальную) сумму**. Доступ к глобальной сумме защищён **критической секцией** (`lock`). Результат вычисляется как `глобальная_сумма / (3 * N)`.

Три режима для сравнения:

| Режим      | Описание                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| `critical` | критическая секция на каждое слагаемое (прямой аналог `#pragma omp critical` внутри цикла), много блокировок  |
| `local`    | каждый поток копит локальную сумму и входит в критическую секцию один раз                                      |
| `race`     | без синхронизации: демонстрация гонки данных, результат может оказаться неверным                               |

Режим `race` нужен только для демонстрации: на больших файлах результат обычно не совпадает с эталоном, на малых гонка может не проявиться. Итоговый признак `OK: true` учитывает только `critical` и `local`.

## Запуск

```bash
cd lab4
dotnet run -c Release -- gen points.txt 10000000      # большой файл со случайными точками
dotnet run -c Release -- sample_points.txt            # маленький пример (результат 0.5)
dotnet run -c Release -- points.txt all               # все режимы
dotnet run -c Release -- points.txt critical          # один режим
```

Формат: `<файл> [critical|local|race|all]`. Формат входного файла описан в `lab3/README.md`.

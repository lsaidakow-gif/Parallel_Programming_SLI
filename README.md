# Параллельное программирование. Лабораторные работы (C#)

Репозиторий содержит лабораторные работы по параллельному программированию.
Исходные задания взяты из методички по **OpenMP** и адаптированы под язык **C#** (.NET 8).

В методичке задачи сформулированы для OpenMP и языков C/C++ или Fortran.
Здесь аналогичное поведение реализовано стандартными средствами .NET:

- потоки из заданий моделируются объектами `System.Threading.Thread`;
- параллельная область: создание потоков и `Join()` для всех (аналог неявного барьера);
- критические секции: `lock` (`Monitor`);
- атомарные операции: `Interlocked` и `Volatile`;
- распределение итераций цикла между потоками реализовано вручную;
- готовые библиотечные средства, решающие задачу целиком (`Parallel.For`, PLINQ и т.п.), **не используются**.

## Требования

- [.NET SDK 8.0](https://dotnet.microsoft.com/download) или новее (чтобы использовать другую версию, измените `TargetFramework` в `.csproj`).
- Сторонние пакеты не нужны.

## Быстрый старт

```bash
git clone https://github.com/<ваш_логин>/<имя_репозитория>.git
cd <имя_репозитория>

dotnet build ParallelProgramming.sln -c Release

cd lab1/task1 && dotnet run -c Release -- 8
cd ../task2   && dotnet run -c Release -- 8 16000 static
cd ../task3   && dotnet run -c Release -- 8 1000
cd ../../lab2 && dotnet run -c Release -- 8 1000
```

Сборка исполняемого файла:

```bash
dotnet publish -c Release -o out
./out/Lab2 8 1000        # Linux/macOS
.\out\Lab2.exe 8 1000    # Windows PowerShell
```

## Соответствие конструкций OpenMP и реализации в C#

| Конструкция OpenMP      | Аналог в C#                                                                   |
| ----------------------- | ----------------------------------------------------------------------------- |
| `#pragma omp parallel`  | создание группы потоков `Thread`                                              |
| `omp_get_thread_num()`  | параметр `id`, передаваемый в поток                                           |
| `omp_get_num_threads()` | количество созданных потоков (аргумент командной строки)                      |
| `#pragma omp for`       | ручное распределение итераций между потоками                                  |
| `schedule(static)`      | статическое разбиение диапазона итераций                                      |
| `schedule(dynamic)`     | общий счётчик блоков под защитой `lock`                                       |
| `schedule(guided)`      | динамическая выдача блоков уменьшающегося размера                             |
| `#pragma omp critical`  | `lock` / `Monitor`                                                            |
| `#pragma omp atomic`    | `Interlocked`, `Volatile`                                                     |
| `#pragma omp barrier`   | `Thread.Join()` для всех потоков, `Barrier`, `CountdownEvent`                 |
| `#pragma omp ordered`   | `Monitor.Wait/Pulse`, `BlockingCollection`, `CountdownEvent`                  |
| `reduction(...)`        | локальные накопители потоков и ручное объединение                             |
